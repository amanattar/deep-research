# deep-research

A Claude skill for comprehensive, multi-source research with structured citations.

## What it does

Guides Claude to research any topic systematically, synthesize findings from multiple angles, and output a clean report with numbered citations, consensus/debate breakdowns, and source credibility notes.

## When it triggers

- "Research X for me"
- "Give me a deep dive on X"
- "Summarize the current state of X"
- "What do sources say about X?"
- Any request needing synthesized analysis with citations

## Output structure

- Executive Summary
- Key Findings
- Detailed Analysis (by subtopic)
- Areas of Consensus / Debate
- Cited Sources (with credibility notes)
- Gaps and Further Research

## Usage

Drop `SKILL.md` into your Claude skills directory. Claude will automatically apply this skill on research-type prompts.
